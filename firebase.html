🔥 Firebase Realtime Database — project: aiml-58d47

Your Firebase app config is embedded. Create the database and enter its URL here to enable sync:

  1. Open console.firebase.google.com → project aiml-58d47 → Realtime Database → Create Database → choose a location.
  2. Copy the database URL shown at the top (for example, https://PROJECT-default-rtdb.firebaseio.com; use your exact URL).
  3. In the Realtime Database Rules tab, publish the rules below.
  4. Paste the Database URL in the field, press Save & Connect, then share firebase.html and the same room code with classmates.

Realtime Database Rules: These allow read/write only for the room path, so treat the room code as shareable access. Publish in Realtime Database → Rules.

{
  "rules": {
    "rooms": {
      "AIML-LUNCH-2026": {
        ".read": true,
        ".write": true
      }
    }
  }
}

Security: Anyone who knows or guesses the room path can edit the lunch data. For a casual class list this is convenient; avoid storing private information. A stronger setup needs Firebase Authentication and authenticated rules.
